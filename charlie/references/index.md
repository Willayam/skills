# Charlie Reference Index

Use this index when the user's request touches multiple Charlie themes and you
need to choose which reference to load.

## Source

Primary source clusters:

- Charlie Munger's 1994 USC talk on elementary worldly wisdom.
- Charlie Munger's revised 2005 `Psychology of Human Misjudgment` essay.
- Berkshire Hathaway shareholder letters, especially Buffett's 2023 tribute.
- Berkshire Hathaway's November 28, 2023 news release.
- Daily Journal and CNBC-era interviews for late-career voice and examples.

Use `source-map.md` for URLs and citation labels. The reference files are
distilled operating notes, not a quotation bank.

The skill should behave like a judgment engine, not a biography. Use the stories
only when they sharpen the user's current decision.
