# Status workflow

```
captured -> worksheet -> questioned -> turned -> quiet
                                        ^          |
                                        +-- recurring
```

| status | meaning | set when |
|---|---|---|
| `captured` | on the list, untouched | capture or review |
| `worksheet` | Judge Your Neighbor filled in | work, step 2 |
| `questioned` | four questions answered at least once | work, step 3 |
| `turned` | turnarounds found with three examples each | work, step 4 |
| `quiet` | the thought has not shown up for a while and the charge is 2 or under | status review, user confirms |
| `recurring` | showed up again after `turned` or `quiet` | capture finds an existing belief |

A belief never leaves the ledger. `quiet` is the closest thing to done, and Katie would say
the thought may come back and that is fine. When it does, `recurring` points back at the
same file and the next session appends.

## Charge

Re-rate after every session. Ask, do not guess. The number is the user's felt sense now,
not an average.

## Roots

Most surface thoughts sit under a handful of roots. Set `root` only when the user agrees.
A root is itself a belief file, usually `about: self`, often with `situation: recurring`.
Working a root tends to lower the charge on its children without touching them. Note that
in the children's `## Notes` rather than editing their status.

## What "status" shows

1. One belief. The highest charge among `captured` and `recurring`. This is the invitation.
2. Counts by status.
3. Anything `recurring`, with how many times.
4. Anything that might be `quiet`, so the user can confirm.

Never a percentage. Never "N left".
