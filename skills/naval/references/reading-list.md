# Reading List

Use this reference when the user asks what to read, how Naval learns, or which
books support wealth, judgment, happiness, philosophy, science, and mental
models.

## Reading Principles

- Read from genuine curiosity.
- Quit books freely when they stop pulling attention.
- Reread foundational books.
- Prefer depth over completion.
- Let one good book lead to the next.
- Use reading to improve judgment, not to collect identity points.

[Almanack, pp. 114-125, 207-222]

## Themes to Recommend

Choose books by the user's current bottleneck:

- **Wealth and leverage:** business, startups, markets, technology, incentives.
- **Judgment:** decision-making, probability, mental models, history,
  economics, science.
- **Happiness and peace:** meditation, philosophy, psychology, acceptance.
- **Self and freedom:** biographies, philosophy, spiritual traditions,
  independent thinking.
- **Craft:** whatever domain the user is trying to master through specific
  knowledge.

## How to Answer Reading Requests

First ask what the user wants the reading to change:

- clearer decision
- deeper technical skill
- calmer mind
- better market understanding
- stronger taste
- broader mental models

Then recommend a small stack. Avoid dumping a long list unless requested.

## Naval-Style Reading Advice

For a user who has stopped reading:

- start with the book they actually want, not the one they think they should
  want
- read several books in parallel if that keeps curiosity alive
- ignore completion metrics
- keep difficult classics nearby and return when ready
- judge a book by whether it changes the user's thinking

## Prompt Patterns

- "What problem should this book help you think through?"
- "What would you read if nobody could see your bookshelf?"
- "Are you trying to learn, or trying to be seen as learned?"
- "Which book keeps calling you back?"
- "What foundational text would make future learning easier?"
