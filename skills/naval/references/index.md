# Naval Reference Index

Use this index when the user's request touches multiple Naval themes and you
need to choose which reference to load.

## Source

Primary source: Eric Jorgenson, `The Almanack of Naval Ravikant: A Guide to
Wealth and Happiness`, free PDF:
`https://navalmanack.s3.amazonaws.com/Eric-Jorgenson_The-Almanack-of-Naval-Ravikant_Final.pdf`.

References use printed book pages as `[Almanack, p. N]` or
`[Almanack, pp. N-M]`. Use the notes as distilled operating guidance, not as
verbatim quotation.

## Routing

- **Wealth and leverage:** Read `wealth-and-leverage.md` when the user is
  deciding how to make money, escape hourly work, build scalable assets, focus,
  get lucky, or be patient.
- **Specific knowledge, accountability, equity:** Read
  `specific-knowledge-accountability-equity.md` when the user is choosing what
  to build, looking for uniqueness, deciding whether to take ownership, or
  evaluating equity versus salary or consulting.
- **Judgment and reading:** Read `judgment-and-reading.md` when the user needs
  clearer thinking, decision-making, mental models, identity shedding, or a
  reading/learning strategy.
- **Happiness:** Read `happiness.md` when the user is anxious, dissatisfied,
  envious, desire-driven, chasing success for relief, or asking about peace.
- **Self and philosophy:** Read `self-and-philosophy.md` when the user asks
  about values, self-care, meditation, meaning, freedom, rational Buddhism, or
  living according to internal standards.
- **Reading list:** Read `reading-list.md` when the user asks what to read, how
  Naval learns, or which books support wealth, judgment, happiness, philosophy,
  science, and mental models.
- **Condensed methods:** Read `naval-methods.md` for a quick checklist, prompt
  patterns, and cross-book operating principles.
- **Source map:** Read `source-map.md` when you need the book's section/page
  structure.

## Response Principle

The skill should behave like a strategic and philosophical lens, not a fan page.
Use stories and aphorisms only to clarify the user's current tradeoff.
